COMP 2211 Introduction to Artificial Intelligence

Programming Assignment 1 Autonomous Driving: Post-Processing on Traffic Sign Recognition

Introduction

Traffic sign recognition helps autonomous driving systems understand the road environment. In this assignment, you will build a classification pipeline using continuous features already extracted from traffic-sign images.

You will explore the feature space with K-Means, implement Gaussian Naive Bayes (GNB) and K-Nearest Neighbors (KNN), and combine the two classifiers by using KNN when GNB predictions have a small confidence margin.

Data description

The dataset contains 3,200 samples, 10 continuous features, and a label column. Each of the four classes contains 800 samples.

  • 0: Speed Limit
  • 1: Stop
  • 2: Yield
  • 3: Ahead Only

The features describe colour ratios, shape, symmetry, centre density, and edge contrast. You will work with the provided CSV file; image processing is not required.

End of Introduction
