Introduction

Implement K-Means clustering from scratch with NumPy to group Pokémon by their battle statistics. Filter rows using Total >= 500, then cluster using HP, Attack, and Defense.

Download Pokemon.csv for the main tasks and pokemon_cluster_subset.csv for optional exploration. Keep the data/ folder next to files/, or upload both CSVs to your Colab working directory.

Use pandas for loading/filtering and NumPy for standardization and K-Means. Scikit-learn is allowed only for review demonstrations and the optional PCA visualization.

End of Introduction

Lab Works

This lab consists of 4 main tasks, followed by an ungraded PCA visualization:

  • Task 1: Load & Filter: Filter Pokémon with Total >= 500, select HP/Attack/Defense, and drop missing selected values.
  • Task 2: Standardize Features: Use NumPy sample z-score standardization (ddof=1); map constant columns to zero.
  • Task 3: K-Means from Scratch: Implement centroid initialization, label assignment, and centroid updates.
  • Task 4: Elbow Method: Calculate inertia without loops and plot K=2 through 18 to discuss a reasonable K.

Part 1: lab4_review.ipynb. Part 2: lab4_tasks.ipynb.

Frequently Asked Questions

Q: Can I modify the provided skeleton code outside of the TODO?
A: No, you are not encouraged to do so. Besides, if you add any code outside the function definition, you should either remove it for submission or put it under if __name__ == "__main__":.

Q: Can I modify the numerical type of data in my code (e.g., change int to float32)?
A: Use floating-point arithmetic for standardization and means. Avoid reducing precision to float32 or rounding intermediate results; integer inputs must still yield floating-point results.

Q: How do I calculate movement between old and updated centroids?
A: Please use the L2-norm to calculate the differences between the old centroids and the updated ones.

Q: Should I update the centroids before breaking out of the loop when the convergence condition is met?
A: For this lab, retain the old centroids when all movements are below 0.01. Recompute labels from the final centroids before returning, even when the iteration limit is reached. For an empty cluster j, use X[j % n_samples], as specified in the notebook.
