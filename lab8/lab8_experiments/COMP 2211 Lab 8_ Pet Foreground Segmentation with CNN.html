Introduction

Image segmentation predicts a label for each pixel in an image. Instead of only answering what appears in an image, a segmentation model also predicts where the object is. In this lab, a CNN learns to separate the pet foreground from border and background pixels.

Dataset: Oxford-IIIT Pet

The supplied archive contains 3,680 paired images and trimaps across 37 breeds. Images are RGB; model inputs are float32 in [0,1] with shape (128,128,3). Targets have shape (128,128,1). For this lab, the original trimap is simplified into a binary foreground mask: pet pixels are labeled 1, while border and background pixels are labeled 0.

Item Role Description
RGB image Raw input A pet image resized and normalized for CNN training.
Trimap annotation Original label A pixel-level annotation with pet, border, and background regions.
Binary foreground mask Target A simplified mask where pet pixels are 1 and all other pixels are 0.

Lab Work

Download lab8_tasks.ipynb and open it in Google Colab. Download data.zip, then place data.zip at the path shown in the setup cell. In Colab this is MyDrive/COMP2211/Lab8/data.zip; for a local runtime, change DATA_ZIP. Extracted files must be under data/images and data/annotations/trimaps.

Task 1

Data Loading and Processing

Implement the deterministic 80/20 split in DataLoader. The provided helpers load paired images and trimaps, resize to 128 x 128, normalize RGB images, and build binary foreground masks.

Task 2

Model Building

Implement a BackgroundSeparater model by subclassing tf.keras.Model. The CNN should output a foreground probability mask with shape (batch, 128, 128, 1).

Task 3

Customized IoU Metric

Implement a stateful IoUScore metric that accumulates intersection and union across batches, so Keras can report meaningful segmentation performance.

Task 4

Model Training

Compile the segmentation model with BinaryCrossentropy, choose an optimizer, train with validation data, inspect mask predictions, and save the final checkpoint.

Frequently Asked Questions

Do I need to improve a specific CNN?

No. Implement a correct segmentation CNN and IoU metric. Architecture and optimizer choices are open; no novel architecture is required.

Why does my output shape differ from the review?

The MNIST review predicts ten digit probabilities. The Pet task outputs one foreground probability per pixel: (batch,128,128,1). Keep masks binary rather than one-hot.

My IoU is zero early in training. Is it broken?

Use the three toy IoU checks in the notebook first. A model predicting only background can legitimately have zero IoU. Inspect loss and predicted masks; use the provided reference training settings as a starting point.

Which weights should I submit?

Your own checkpoint, selected by validation IoU and saved as model.weights.h5. The notebook reloads it before evaluation. Do not submit the MNIST review model.

Where can I check outputs?

The notebooks include expected sample counts, tensor shapes, IoU examples and save/reload checks. These let you debug locally before submitting. To export a completed notebook, download export_submission.py beside it and run python export_submission.py lab8_tasks.ipynb.
